One line of horror for the make.fun bounty **One Line, One Chill**: a single
sentence, under 200 characters, meant to frighten a reader in one breath.

## The line

> The MRI showed nothing wrong with my brain, except for the small, patient face pressed against the inside of my skull, smiling.

A clean scan with one impossible finding. The scare is earned by what the
sentence withholds — whose face it is, how long it has been waiting — and the
last word, "smiling", lands the blow. No gore, no mirror, no doll, no
basement: one concrete image, one sentence, one chill.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set), with mode `0644`, and prints the same line to
stdout. The file holds exactly the sentence — one sentence, 127 characters,
inside the gate's 1–200 character window.
